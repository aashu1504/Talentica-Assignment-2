SQL Injection Test - sort - Injection
Critical ▼

📋 Description

**Vulnerability Type:** SQL Injection **CWE ID:** CWE-89 **Description:** SQL injection vulnerability allows attackers to manipulate database queries through user input in the /createdb endpoint using GET method with parameter 'sort'. **Technical Details:** The application fails to properly validate and sanitize user input before using it in SQL queries, allowing malicious SQL code to be executed in the database context. Specifically, the 'sort' parameter accepts the payload '' OR '1'='1' which demonstrates the vulnerability. **Root Cause:** Lack of input validation, use of string concatenation for SQL queries instead of parameterized queries, missing input sanitization In this case, the application fails to properly validate the 'sort' parameter before processing. **Attack Vectors:** URL parameters, Form inputs, HTTP headers, JSON payloads, XML payloads **Prerequisites:** Direct database access, User input used in SQL queries, Lack of input validation **Exploitation Conditions:** User input is directly concatenated into SQL queries without proper sanitization or parameterization The payload '' OR '1'='1' can be sent to /createdb via GET request to exploit this vulnerability. **Affected Components:** Database layer, Application logic, Data access layer, API endpoints **Data Flow Analysis:** User input flows from HTTP request → Application logic → Database query without validation **Architecture Impact:** Compromises the entire database layer and potentially the underlying infrastructure
